# HABU EV INDUSTRY - Electric Rickshaw & EV Solutions Website

A modern, responsive React website for advertising Electric Rickshaws and EV solutions in India.

## Features

- 🚗 **Home Page** - Hero section with key highlights and CTAs
- 📖 **About Us** - Company mission, vision, and trust indicators
- 🛍️ **Products** - Two Wheelers, Customized Products, and Batteries
- 🤝 **Dealer Partner** - Benefits and registration form
- 🎓 **EV Training** - Training programs and course highlights

## Tech Stack

- React 18
- React Router DOM
- Vite
- Modern CSS (Responsive Design)

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Project Structure

```
src/
├── components/     # Reusable components
├── pages/         # Page components
├── styles/        # CSS files
├── assets/        # Images and static files
└── App.jsx        # Main app component with routing
```
